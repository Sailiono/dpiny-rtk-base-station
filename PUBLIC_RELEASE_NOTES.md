# Public Release Notes

This repository is a sanitized snapshot derived from the private dpiny engineering repository.

Included material covers firmware source, target configuration, host-side verification tools, and public documentation. The original private history, vendor manuals, internal hardware spreadsheets, generated firmware, bench captures, local IDE/AI configuration, and transient test reports are deliberately excluded.

The snapshot was checked for common credential patterns, personal absolute paths, excluded file formats, and bundled third-party license notices. Functional results referenced in the README come from the original real-hardware workflow; hardware tests were not rerun solely for publication.
